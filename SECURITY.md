# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Hakscan itself, please open a private
security advisory on GitHub or contact the maintainer rather than filing a
public issue. We will acknowledge your report and work on a fix.

## Responsible use

Hakscan is intended for authorized security testing only (systems you own or
have explicit written permission to test). Misuse against systems without
permission is illegal and is not supported by this project.
